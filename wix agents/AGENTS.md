# Agent notes

This repository is a **Wix agent kit**, not the live Wix site.

Before any Wix work:

1. Read `WHAT-YOU-NEED-TO-DO.md`.
2. Read `templates/SITE_INFO.md` if the user filled it in.
3. Use skills in `.cursor/skills/` (copied from `vendor/wix-skills/skills/`).
4. Use the Wix MCP at `https://mcp.wix.com/mcp`.
5. If `site-repo/` exists, that clone is the Wix Git Integration project. Prefer editing it over inventing Velo files here.

Never commit `.env` or API keys.
